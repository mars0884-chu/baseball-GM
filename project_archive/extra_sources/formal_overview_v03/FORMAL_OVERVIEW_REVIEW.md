# 《決勝GM》正式圖像總覽 v0.3

> 狀態：等待產品擁有者最終確認。  
> 禁止用途：尚不可拆分為正式素材或導入 v48。

## 01｜角色與UI最高參考（已替換）

正式參考檔：`01_CANONICAL_character_ui_reference.png`

- 人物以介面圖標化為優先，不追求清楚寫實的五官與細部。
- 帽子與頭部主導輪廓，身體極小，四肢只保留動作必要部分。
- 表情主要靠粗眉、眼睛方向、腮紅與簡單嘴型快速辨認。
- 球員在64px左右仍須看得出身份、表情與職務。
- 粗黑線、簡化賽璐璐陰影、高飽和日式運動遊戲風格。

淘汰參考：`01_character_style_final_review.png`

- 淘汰原因：五官、頭髮、服裝與陰影過度清楚精緻，不符合產品擁有者偏好的簡潔圖標人物。
- 不得再以此檔指導人物生成。

## 02｜UI/UX六大畫面（已通過）

正式參考檔：`01_CANONICAL_character_ui_reference.png`

同內容備份：`02_uiux_six_screens_final_review.png`

- 主控台：港灣球場、KPI、戰績、待辦。
- 財務：營收圖、預算條、資產資訊。
- 名單：球員卡、雷達圖、球員列。
- 交易：雙方資產、交換箭頭、接受與拒絕。
- 教練：戰術板、教練卡與球員配置。
- 郵件：事件、通知、里程碑與新聞縮圖。
- 白底資料卡維持長時間閱讀性，高飽和色只集中在操作與狀態。
- 畫面中的船錨與隊徽為風格佔位，不是正式聯盟或球隊標誌。

## 03｜資產語言（已通過）

檔案：`03_asset_language_final_review.png`

- 隊徽展示動物、地方產業與交通意象，避免玄幻詞彙與電競魔法徽章。
- 球衣展示白色主場、淺藍／灰色客場、條紋、深色與城市版。
- 圖示與按鍵採粗線、硬邊陰影、少量高飽和色。
- 額外涵蓋票券、退休背號、獎盃、里程碑及球場背景。
- 所有徽章、帽徽、球衣符號與動物都只是風格範例，不代表20隊正式名單。
