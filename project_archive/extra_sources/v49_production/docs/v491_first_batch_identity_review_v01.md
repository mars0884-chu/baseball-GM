# 《決勝GM》v491 第一批球隊品牌驗證

> 日期：2026-07-25  
> 範圍：T1 臨海獵鯊、T10 嘉禾金穗、T12 金川礦工  
> 用途：先用海洋動物型、地方農業型、交通工業型三種題材驗證聯盟資產語言。  
> 狀態：兩套球衣版概念驗證完成，尚未拆成正式透明隊徽、帽徽與球衣圖層。

## 一、共同設計規則

- 依 v491 固定 `teamId` 綁定，不以顯示隊名作資產鍵。
- 粗墨藍外框、平面色塊、二階賽璐璐、高飽和焦點色。
- 主隊徽需在 64px 仍保留主題輪廓；帽徽需能進一步縮至 24～32px。
- 每隊固定兩套球衣：白色系主場＋球隊主色系客場。
- 灰色球衣取消；原城市版的地方圖樣可整合進客場球衣，但不另設第三套。
- 不使用真實球隊標誌、商標、文字、字母或球衣號碼。
- 此階段只做概念板；正式匯入前仍需向量化／透明切圖與小尺寸修線。

## 二、T1 臨海獵鯊

檔案：

- `previews/T1_linhai_harbor_sharks_identity_board_v01.png`
- `previews/T1_linhai_harbor_sharks_identity_board_v02_two_uniforms.png`（現行）
- `previews/T1_primary_emblem_variants_v02.png`

建議：

- 主隊徽採「盾形鯊魚＋浪＋燈塔」。
- 帽徽採「鯊鰭＋浪」圓形簡化語言。
- 主色 `#063B66`、輔色 `#20C6D7`，珊瑚紅只作燈塔小焦點。
- 球衣固定為白色主場＋深海軍藍客場；原淺藍灰球衣取消。
- 正式化時減少牙齒與浪花節點，避免 32px 糊成一團。

## 三、T10 嘉禾金穗

檔案：

- `previews/T10_jiahe_golden_harvest_identity_board_v01.png`
- `previews/T10_jiahe_golden_harvest_identity_board_v02_two_uniforms.png`（現行）

第一輪判定：

- 主隊徽的稻穗、盾形本壘板與棒球縫線關係清楚，地方產業感成立。
- 獨立稻穗帽徽輪廓乾淨，適合後續再簡化為 24～32px。
- 白色主場搭配深綠客場；客場田野弧線可形成隊伍專屬圖樣。
- 原暖灰球衣取消。
- 主色 `#2F6B3C`、輔色 `#E9B949`，與聯盟其他海洋／工業隊伍有足夠差異。

正式化待修：

1. 主徽左右兩側棒球縫線再減少節點。
2. 帽徽只保留 5～7 顆大型穀粒，避免小尺寸碎裂。
3. 客場球衣田野線條縮減為兩至三道粗弧線。
4. 建立透明主徽、帽徽與圓形副徽獨立檔。

## 四、T12 金川礦工

檔案：

- `previews/T12_jinchuan_miners_identity_board_v01.png`
- `previews/T12_jinchuan_miners_identity_board_v02_two_uniforms.png`（現行）

第一輪判定：

- 礦燈是最強識別物，搭配鐵軌與齒輪後具有完整地方故事。
- 帽徽的安全帽＋礦燈輪廓清晰，適合 24～32px；正式版可再移除一層內圈。
- 白色主場搭配黑色客場；安全橘在深色球衣與 UI 上具有強焦點。
- 原鋼灰球衣取消。
- 主色 `#343A40`、輔色 `#F28C28`，整體成熟但仍符合遊戲的歡樂職棒語言。

正式化待修：

1. 主徽齒輪減少齒數，山峰與鐵軌線條再加粗。
2. 礦燈中心改為實心暖白／橘色圓面，避免縮小後像空洞。
3. 客場球衣鋼構線條簡化，避免與胸前隊徽競爭。
4. 建立透明主徽、帽徽與圓形副徽獨立檔。

## 五、第一批結論

三種題材已能使用同一套視覺語言而保持差異：

- T1：快速、港灣、海洋動勢。
- T10：穩定、地方農業、金色收穫。
- T12：堅韌、山城工業、黑橘安全識別。

下一步應先將三隊主徽與帽徽做正式切圖／64px 驗證，再以同一規格擴展至其餘 17 隊。
