# 《決勝GM》美編摘要記憶

> 最後更新：2026-07-23  
> 用途：供後續 Codex 對話與 Claude 交接恢復專案脈絡。  
> 權限狀態：品牌、UI與資產語言已確認；人物最高參考已替換。v48僅供參考，禁止正式導入；等待v49後重新比對與套入。

## 一、工作分工與不可違反原則

- Codex 負責所有視覺美術、背景、UI/UX視覺規格、圖示、按鍵、角色、隊徽、球衣與交接文件。
- Claude 負責程式實作、文字資料替換、主題包接線、組合式肖像顯示與最終封裝。
- Codex 不修改遊戲規則、數值、功能、資料運算或程式架構。
- 正式美術套入前必須先取得產品擁有者確認。
- 原始 v48 ZIP 內既有程式檔必須完整保留；美術交付須附 SHA-256 比對與 Claude 可讀摘要。
- 遊戲規則、數值、功能與架構完全不變；允許 Claude 依定案文件替換遊戲名稱、本國名稱、球隊名稱、隊色與相關顯示文字。

## 二、品牌定案

- 中文名稱：《決勝GM》
- 英文副標題：FRONT OFFICE BASEBALL
- 標誌構圖：藍色中文「決勝」＋粉紅色大寫「GM」＋深藍外框。
- 標誌方向：明亮、短而有力，小尺寸仍須清楚辨識。

## 三、世界設定

- 完全架空的亞洲職棒聯盟，以台灣為主要靈感。
- 各隊具有不同亞洲文化特色，命名可參考台灣、美國、日本與韓國職棒方式。
- 避免玄幻、仙俠、魔法及過度空泛的名稱。
- 國家組成為20個真實國家＋20個架空國家。
- 真實國家中的台灣必須使用正確的中華民國國旗。
- 20個架空國家包含玩家本國，分別影射亞洲、美洲、歐洲等棒球文化。
- 玩家本國：海嶺共和國。
- 海嶺共和國國旗：正式選用A案「山海線」。
- 海嶺共和國國旗使用藍、白、綠、粉紅，不直接使用棒球、球棒或GM圖案，且不得近似真實國旗。

## 四、整體美術風格

- A案「球場嘉年華」的明亮感＋C案「港灣球會」的亞洲地方職棒風格。
- 情緒比例：70%熱血歡樂＋30%成熟沉重。
- 日式趣味超誇張二頭身、粗黑線條、二階賽璐璐平塗、高飽和活力波普。
- 介面保持白底與高可讀性；高飽和色集中於操作、狀態、標籤、圖示與焦點。
- 禁止突然切換為寫實、柔焦、薄線、3D塑膠或幼兒卡通風格。

## 五、人物定案

- 人物最高視覺參考：`formal_overview_v03/01_CANONICAL_character_ui_reference.png`。
- 人物以介面圖標化為優先，不追求過度清楚精緻的五官、髮絲、服裝縫線與陰影。
- 約1.5頭身，頭部視覺上約佔全身65%；實際生成時以最高參考圖的觀感為準。
- 帽子與頭部主導輪廓，身體與四肢高度簡化。
- 手可以只露小臂、手掌或手套。
- 腳可以只露鞋子或極短小腿。
- 表情主要依靠粗眉、眼睛方向、腮紅與簡單嘴型快速辨認。
- 64px左右仍須清楚辨認身份、職務與情緒。
- 球棒、手套、麥克風、文件板等職務道具可誇張放大。
- GM、教練、球員、球探、代理人、媒體與職員都維持相同比例。
- 男子職棒；女性可作為球團職員、媒體與球迷角色。
- 人物以中性架空造型為主，同時可有明顯國籍與外貌差異。
- `formal_overview_v03/01_character_style_final_review.png`已淘汰，不得再作為人物生成依據；原因是過度清楚精緻。

## 六、配色定案

- 主藍：#1769D2
- 基底白：#FFFFFF
- 輔綠：#59C78B
- 輔粉：#FF4F87
- 墨藍：#102949
- 以上為遊戲UI、聯盟品牌與海嶺國家代表隊的共通色。
- 20支職業隊另有獨立隊色，避免所有球隊難以辨認。

## 七、球衣與球隊

- 主場球衣通常以純白為底。
- 每隊固定只製作兩套球衣：主場白色系＋客場球隊主色系。
- 灰色球衣取消，不製作第三套城市版。
- 客場球衣可使用深色、條紋與地方圖樣，但仍須維持各隊獨立隊色及清楚辨識。
- 球帽、文字、護具、領口與袖口使用各隊主色及輔色。
- 20隊結構：8隊城市型＋6隊企業型＋6隊概念型。
- Codex負責隊名、架空城市、吉祥物、主輔色、隊徽、兩套球衣、帽徽及球場視覺特色。

## 八、球員肖像

- 每位球員具有獨立且固定的外貌。
- 採固定playerId驅動的組合式肖像，而非準備上千張完整圖片。
- 美術零件包含臉型、膚色、五官、髮型、鬍型、帽子、球衣、表情與配件。
- 同一球員跨畫面與讀檔後必須維持相同外貌。
- 球員轉隊後可更換帽子與球衣，但臉部身份不得改變。
- 組合與固定ID邏輯由Claude實作。
